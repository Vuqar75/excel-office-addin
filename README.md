# Excel Data Assistant

Office.js-надстройка для Excel Online и настольного Excel с локальным компонентом Desktop Companion для системных функций Windows.

## Возможности

- анализ, очистка, дубликаты, сверка и автоматические отчёты;
- инструменты ячеек, текста, фильтрации, листов и преобразования таблиц;
- безопасное умное заполнение формул и автоматически расширяемые таблицы;
- библиотека из 67 формул: поиск, категории, избранное и недавние шаблоны;
- локальная проверка формул и AI-генерация через Desktop Companion;
- пакетные операции Desktop Pro: книги, CSV, PDF, Power Query и диагностика;
- журнал операций, резервные листы и переносимые настройки.

## Платформы

- **Excel Online:** все Office.js-инструменты и библиотека формул. AI без облачного шлюза недоступен.
- **Excel для Windows:** Office.js-инструменты и Desktop Pro через локальный мост.
- **Excel для macOS:** Office.js-инструменты; системные команды Windows недоступны.

Каждая кнопка в панели имеет метку `Online + Desktop` или `Desktop · мост`.

## Безопасность

- диапазоны свыше 100 000 ячеек блокируются;
- 19 массовых операций показывают адрес, размер и действие до запуска;
- рискованная операция требует повторного нажатия в течение 10 секунд;
- изменяющие команды создают резервные листы;
- вставка формулы блокируется для занятой ячейки, исходного диапазона, циклической ссылки и синтаксической ошибки;
- ключ OpenAI хранится только локальным компонентом и не экспортируется с настройками.

## Разработка и проверка

```text
node scripts/validate-release.mjs
node scripts/test-formula-library.mjs
node scripts/test-formula-experience.mjs
node scripts/test-navigation.mjs
node scripts/test-safety-center.mjs
node scripts/test-plex-tools.mjs
```

Корпоративная политика Windows может блокировать запуск `node`/`npx`; в рабочей среде те же модули запускаются через встроенную среду Codex.

Подробное руководство: [USER_GUIDE.md](USER_GUIDE.md). Протокол локального моста: [desktop-companion/PROTOCOL.md](desktop-companion/PROTOCOL.md).
