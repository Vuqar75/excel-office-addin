# Excel Data Assistant 2.0

Office.js-надстройка для анализа, очистки, дубликатов, сверки и автоматических отчётов.

## Возможности 2.0

- выбор столбцов для поиска дубликатов;
- выбор ключевого столбца и контроль повторяющихся ключей;
- резервные копии и восстановление;
- типы данных, формулы, даты и проценты в отчётах;
- прогресс, лимит диапазона и журнал операций;
- русский, азербайджанский и английский интерфейс;
- кнопка открытия панели на ленте Excel.
